# Worship With Me

Church X Sunday app. One program: slides, run sheet, license log, and new-here card.

The older trial at ever-garden-light-cloud.grok.me is not this app. Use this site.

Open `index.html` on the church laptop. It works offline after the first load. Services, songs, guests, and the CCLI log stay in that browser.

## Sunday

- Present opens a projector window. The laptop keeps the run sheet. Rehearse stays on one screen.
- Export Sunday and Import Sunday are on the Sunday screen. The file name includes the date.
- The church name is the title slide and the browser tab. A licensed song ends with the author, copyright line, and license number.
- Arrows move slides. B blacks the screen. T shows the title on the projector, or stage notes while rehearsing. Esc leaves.
- Public-domain hymns are built in.
- Paste licensed lyrics from SongSelect only if the church holds a CCLI license. Streaming lyrics may need a separate streaming license.
- King James text in the sample passages is public domain in the United States.
