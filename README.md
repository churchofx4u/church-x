# Church X

Sunday slides, run sheet, CCLI log, and new-here card.

Open `index.html` on the church laptop. It works offline after the first load. Services, songs, guests, and the CCLI log stay in that browser.

## Sunday

- Arrows move slides. B blacks the screen. T shows stage notes. Esc leaves.
- Public-domain hymns are built in.
- Paste licensed lyrics from SongSelect only if the church holds a CCLI license. Streaming lyrics may need a separate streaming license.
- King James text in the sample passages is public domain in the United States.

## Publish

GitHub Pages serves this folder from the `main` branch.

Live app: https://churchofx4u.github.io/church-x/

After it is live, open New here, paste that URL, and save. The QR then points at the welcome card.

Billing is not connected. Do not charge until a church has used this on a real Sunday.
